# Indice Navideño de canciones
En este repositorio está alojado un proyecto de clustering con el fin de identificar canciones relacionadas con la Navidad, basado en Spotify Charts.
Corresponde al proyecto final del curso de Introducción a la Ciencia de Datos impartido por el Dr. Marco Antonio Aquino López, del Centro de Investigación en Matemáticas (CIMAT).

Se optó por utilizar un Notebook por el volumen de datos que no se podía manejar fácilmente a nivel local. La URL de acceso a los datos es la siguiente:

https://www.kaggle.com/datasets/dhruvildave/spotify-charts

El archivo "It_s_Time.pdf" son diapositivas utilizadas para una breve presentación de resultados.
